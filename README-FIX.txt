Bazarek final fix

این فایل فقط تغییرات لازم برای رفع دو مشکل نسخه قبلی را دارد:
1) صفحه اصلی به API عمومی /api/listings روی bazarek.onrender.com وصل می‌شود و دیگر روی لودینگ بی‌نهایت نمی‌ماند.
2) نشست کاربر با access token + refresh token واقعی Supabase ذخیره و تمدید می‌شود.
3) توکن‌های ساختگی نسخه‌های قدیمی local_* هنگام اجرای برنامه پاک می‌شوند تا خطای «نشست شما منقضی شده است» باقی نماند.
4) آپلود تصاویر و انتشار آگهی در صورت 401 یک بار با نشست تازه تلاش می‌شود.
5) اگر آگهی‌ای وجود نداشته باشد پیام «هنوز هیچ آگهی فعالی ثبت نشده است.» نمایش داده می‌شود؛ اگر سرور خطا بدهد، خطای اتصال و دکمه «تلاش دوباره» نمایش داده می‌شود.
