# 🚀 دستیار فروش هوشمند افغانستان

سیستم مدیریت فروشگاه، تولید آگهی هوشمند و صدور فاکتور برای فروشندگان آنلاین در افغانستان.

## 🛠️ تکنولوژی‌ها
- **Frontend:** Flutter
- **Backend:** Node.js / Express
- **AI Engine:** Google Gemini Flash API

## ⚡ راه اندازی بخش بک‌اند
```bash
cd backend
npm install
npm start
