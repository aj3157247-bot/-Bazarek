بازارک — به‌روزرسانی ظاهر وب با الهام از آمازون

فایل داخل این ZIP:
- lib/main.dart

این تغییرات برای نسخه وب طراحی شده‌اند:
- سربرگ سرمه‌ای شبیه فروشگاه‌های بزرگ آنلاین
- منوی کناری در صفحه‌های عریض دسکتاپ
- بنر معرفی و چیدمان واکنش‌گرا در صفحه اصلی
- رنگ‌بندی وب با آبی فروشگاهی و حفظ ساختار فعلی آگهی‌ها

قابلیت‌های قبلی از همان کد و صفحه‌های فعلی استفاده می‌کنند؛ از جمله ورود/ثبت‌نام، آگهی‌ها، علاقه‌مندی‌ها، چت، پروفایل و مسیر پنل مدیریت. منطق پرداخت دستی یا APIهای بک‌اند در این بسته تغییر نکرده‌اند.

محدوده تغییر:
- تمام تغییرات نمایشی جدید با kIsWeb یا در مسیر مخصوص وب فعال می‌شوند.
- شاخه اپلیکیشن اندروید عمداً تغییر رفتاری داده نشده است.
- فایل‌های workflow ساخت APK، backend، پرداخت دستی و پنل مدیریت تغییر نکرده‌اند.

نصب:
1. در مخزن متصل به سرویس bazarek-web، فقط فایل lib/main.dart را با فایل همین ZIP جایگزین کن.
2. Commit کن.
3. در Render سرویس bazarek-web را باز کن و Manual Deploy → Deploy latest commit را اجرا کن.
4. مطمئن شو Dockerfile Path روی ./Dockerfile.web است.

محدودیت بررسی:
این محیط Flutter SDK در دسترس نداشت؛ بنابراین Build و تست Render انجام نشده است. قبل از اعلام موفقیت، نتیجه Build را در Render بررسی کن.
