بازارک — ارتقای پنل مدیریت و رسیدگی به گزارش‌ها

فایل‌های تغییرکرده:
- lib/admin_panel_screen.dart
- lib/main.dart
- backend/src/server.js
- supabase/migrations/202609100001_admin_moderation_finance_security.sql

مهم:
1) فایل migration جدید را در Supabase SQL Editor اجرا کنید.
2) سه فایل Dart/Backend را در مسیرهای اصلی پروژه جایگزین کنید.
3) Backend روی Render را Deploy کنید.
4) Flutter Web/Android را از GitHub دوباره Build/Deploy کنید.

قابلیت‌های جدید:
- سفارش ارتقای آگهی: نام کاربر، شماره، نام آگهی، تصویر آگهی، بسته و شماره پیگیری/رسید نمایش داده می‌شود.
- قبل از تأیید پرداخت می‌توان خود آگهی را بازبینی کرد.
- شکایات: گزارش‌دهنده، صاحب آگهی، شماره‌ها، آگهی و تصویر آن نمایش داده می‌شود.
- رسیدگی کامل به شکایت: بستن آگهی، ارسال هشدار به صاحب آگهی، تشکر از گزارش‌دهنده و ثبت یادداشت مدیر.
- اعلان داخل برنامه برای کاربر پس از هشدار، مسدودی، نتیجه پرداخت و تشکر بابت گزارش درست.
- داشبورد: کارت‌های کاربران/آگهی‌ها/شکایات/درآمد/مالی/امنیت قابل کلیک هستند و مستقیماً بخش مربوط را باز می‌کنند.
- درآمد فقط از پرداخت‌های تأییدشده محاسبه می‌شود و مبلغ در انتظار تأیید جدا نمایش داده می‌شود.
- تراکنش‌های کیف پول از فهرست اصلی قابل بایگانی هستند تا فهرست شلوغ نشود؛ رکورد مالی حذف فیزیکی نمی‌شود.
- بخش امنیت: ورودهای موفق و ناموفق مدیریت، ایمیل، IP و زمان ثبت می‌شود.
- آپلود عکس پروفایل در Flutter Web با bytes انجام می‌شود تا خطای Blob URL برطرف شود.
