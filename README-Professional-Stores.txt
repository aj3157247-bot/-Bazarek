بازارک — تغییرات فروشگاه حرفه‌ای

فایل‌های تغییر داده‌شده:
1) lib/main.dart
   - دکمه واضح «ثبت‌نام / ورود» در بالای صفحه.
   - حذف بخش «خرید بر اساس دسته‌بندی» از صفحه اصلی.
   - جایگزینی آن با «فروشگاه‌های حرفه‌ای» با محصولات، تعداد محصولات و قیمت شروع.
   - صفحه فهرست فروشگاه‌ها.
   - صفحه فروشگاه با نمایش حرفه‌ای محصولات و قیمت‌ها.
   - پلن‌های فروشگاه حرفه‌ای در صفحه Boost.
   - ماهانه 600 افغانی / سالانه 6000 افغانی.
   - حفظ جستجو، آگهی‌ها، حساب، گفتگو، علاقه‌مندی‌ها و سایر قابلیت‌های قبلی.

2) backend/src/server.js
   - اضافه شدن store_monthly با قیمت 600 AFN و مدت 30 روز.
   - اضافه شدن store_yearly با قیمت 6000 AFN و مدت 365 روز.
   - فعال‌سازی صحیح مدت اشتراک فروشگاه هنگام تأیید مدیریت.
   - پلن فروشگاه دیگر plan پروفایل کاربر را به pro/business تغییر نمی‌دهد.

3) supabase/migrations/202609200001_professional_store_plans.sql
   - اجازه ثبت store_monthly و store_yearly در seller_subscriptions.

مهم:
قبل از اینکه خرید فروشگاه حرفه‌ای در Backend کار کند، فایل migration جدید را یک‌بار در Supabase SQL Editor اجرا کنید.

اگر Backend شما از همین repository و backend/src/server.js اجرا می‌شود، بعد از commit تغییرات، Backend را هم Deploy کنید.

این نسخه از main.dart از API جدید file_picker v12 استفاده می‌کند و دیگر FilePicker.platform ندارد.
