# نسخه وب بازارک

این پروژه با همان کد Flutter فعلی، نسخه Web نیز می‌سازد؛ بنابراین اپ Android و سایت از همان API بازارک استفاده می‌کنند.

## اجرای سایت روی Render

1. همین Repository را در Render به عنوان یک **Web Service** جدید اضافه کنید.
2. Runtime را روی **Docker** بگذارید.
3. Dockerfile را `Dockerfile.web` انتخاب کنید.
4. سرویس را Deploy کنید.
5. Backend فعلی بازارک باید همچنان روی `https://bazarek.onrender.com/api` فعال باشد.

فایل `render-web.yaml` نمونه تنظیمات سرویس وب است.

## نکته مهم

- سایت حساب کاربری، آگهی‌ها، Boost، پرداخت، عکس‌ها و API فعلی را با همان Backend استفاده می‌کند.
- آپلود تصویر پروفایل برای Web با `readAsBytes()` انجام می‌شود تا به مسیر فایل محلی وابسته نباشد.
- هیچ دیتابیس جداگانه‌ای برای سایت ساخته نمی‌شود.
