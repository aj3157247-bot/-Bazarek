بازارک — رابط وب مستقل با طراحی الهام‌گرفته از فروشگاه‌های بزرگ آنلاین

فایل‌ها: web/index.html و Dockerfile.web

فقط همین دو فایل را در مخزن جایگزین کنید. lib/main.dart، android/، workflow ساخت APK، backend، nginx.conf و سیستم پرداخت دستی تغییر نکرده‌اند.

Render: Dockerfile Path = ./Dockerfile.web ، Build Context = . ، Root Directory خالی. سپس Manual Deploy → Deploy latest commit.

رابط به API فعلی https://bazarek.onrender.com/api وصل است و بخش‌های اصلی ورود/ثبت‌نام، جست‌وجو و نمایش آگهی، ثبت/مدیریت آگهی، علاقه‌مندی، گفتگو، پروفایل، کیف پول/اطلاعات پرداخت دستی، پشتیبانی و پنل مدیریت را پیاده می‌کند. بعضی قابلیت‌های تخصصی اپ قدیمی ممکن است هنوز در این رابط وب معادل کامل نداشته باشند؛ برای جلوگیری از دست‌کاری اپ، سورس Flutter آن حفظ شده است.

Build و اتصال زنده API/Render در این محیط قابل اجرا نبود؛ قبل از deploy از مخزن backup بگیرید و لاگ Render را بررسی کنید.
