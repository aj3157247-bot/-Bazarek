قابلیت جدید: دانلود اپلیکیشن بازارک در بخش «حساب من»

در lib/main.dart گزینه «دانلود اپلیکیشن بازارک» بلافاصله زیر حالت شب/روز اضافه شده است.

لینک فعلی دانلود:
https://github.com/aj3157247-bot/Bazarek/releases/latest/download/bazarek.apk

برای اینکه لینک کار کند، در GitHub یک Release بسازید و فایل APK را دقیقاً با نام زیر به آن اضافه کنید:
bazarek.apk

اگر فایل APK نام دیگری داشته باشد، باید مقدار apkUrl در lib/main.dart تغییر کند.
